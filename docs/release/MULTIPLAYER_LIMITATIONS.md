# Multiplayer Limitations

Phase 17 ships the Phase 15 multiplayer foundations already present in PlayWorld Studio and preserves exported host/client verification.

Current scope is intentionally limited. The release candidate does not add production matchmaking, relay infrastructure, account/auth services, voice chat, anti-cheat, rollback networking, dedicated-server fleets, or production real-time collaborative authoring mutation.

Multiplayer remains opt-in. Runtime multiplayer state stays separate from authored creator state. Host/client exported-game verification covers the existing ownership/input and connection foundations; it is not a claim of internet-scale production networking infrastructure.
