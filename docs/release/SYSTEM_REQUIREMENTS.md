# System Requirements

## Supported release target

- 64-bit Windows
- x86_64 processor/runtime
- graphics drivers capable of running Godot 4.7.1
- writable per-user application-data storage for projects, settings, Asset Library metadata, export staging, and installed per-user export templates
- enough free disk space for the creator package, imported assets, project checkpoints, staging data, and exported games

PlayWorld Studio 0.1.0-rc.1 is a Windows release candidate. Other desktop operating systems are not Phase 17 distribution targets.

The package includes the Godot 4.7.1 exporter executable and Windows x86_64 release template required by PlayWorld's game-export pipeline.
