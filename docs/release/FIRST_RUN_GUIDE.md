# First Run Guide

On first launch, PlayWorld Studio opens to Home. No project or shared Asset Library source is required to reach the creator.

Use **Create New World** to choose a world scale, a built-in template, and a biome. Creation opens the workspace and initializes the authored project in per-user project storage.

Use **Settings** for scale, density, motion, performance, and controller-glyph preferences. Use **About** to verify the running product version.

Use **Asset Library** to register external source folders. PlayWorld indexes supported assets while leaving the originals in place. Shared catalog state is user-scoped and is available across projects.

Use **Build / Play** in the workspace to enter Instant Play and return to authoring without replacing the authored project.
