# Quick Start: First Project

1. Launch PlayWorld Studio and select **Create New World**.
2. Name the world.
3. Choose a world scale.
4. Choose a built-in template such as Third Person Adventure.
5. Choose a biome such as Meadow.
6. Create the world and enter the workspace.
7. Use Place to add an entity, then Move / Rotate / Scale to edit it.
8. Save the project.
9. Switch to **Play** for Instant Play, then return to **Build**.
10. Open Asset Library if you want to register external GLTF/GLB/Godot scene sources.
11. Use Export to build a standalone Windows game.

Projects can be reopened from Home after PlayWorld Studio is closed and relaunched.
