# Foliage, Procedural, and Spline Tools

## Foliage
Use instancing/MultiMesh-oriented representation for large populations. Editing uses procedural sets rather than thousands of independent authoring objects.

## Brushes
Paint, erase, replace, density, scale range, rotation, slope filter, altitude filter, biome filter, exclusion masks.

## Procedural sets
Every generated result has a seed, bounds, rule definition, asset query, ownership record, and regeneration mode. Users can regenerate or bake to ordinary entities.

## Splines
Spline-driven systems support roads, paths, fences, walls, guardrails, light rows, rivers, pipes, and custom generators.

## Nondestructive requirement
Procedural operations remain editable until explicitly baked. Changes regenerate owned results instead of leaving orphaned entities.
