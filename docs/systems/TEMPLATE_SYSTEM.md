# Prototype Template System

Templates are data-driven project starters, not forks of the editor.

## Initial templates
Blank Sandbox, Third-Person Adventure, FPS, Survival, RPG, Driving, Walking Simulator.

## Template manifest
Each template declares required runtime modules, starter scenes/entities, input mapping, default camera/player archetype, example graphs, UI/HUD package, export settings, and optional tutorial steps.

## Rule
Projects may add/remove template modules after creation. Choosing a template must not permanently trap the project in one genre.
