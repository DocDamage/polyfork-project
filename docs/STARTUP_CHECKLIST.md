# Startup Checklist

- [ ] Install Godot 4.7.x.
- [ ] Create Git repository.
- [ ] Copy this starter pack into repository root.
- [ ] Keep canonical UI reference committed.
- [ ] Open `project.godot`.
- [ ] Run starter scene.
- [ ] Create initial issue/milestone structure from `TASK_BACKLOG.md`.
- [ ] Begin with `docs/handoffs/CURRENT_HANDOFF.md` only.
- [ ] Do not import the entire external asset library into the Godot project folder; register it through the future library system instead.
