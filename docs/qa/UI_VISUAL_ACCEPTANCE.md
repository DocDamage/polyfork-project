# UI Visual Acceptance

## Reference
`assets/reference/CANONICAL_UI_REFERENCE.png`

## Review method
Capture the running app at the same approximate aspect ratio and compare side-by-side. Review layout hierarchy, viewport dominance, card radius, spacing, dark surface levels, tool-color semantics, typography scale, inspector width, asset-card density, bottom dock proportions, Build|Play prominence, and overall playful polish.

## Defects
Treat the following as defects unless intentionally documented: generic gray Godot UI, flat rectangular enterprise panels, always-visible advanced settings, tiny asset thumbnails, overly dense menus, inconsistent rounding, mismatched tool colors, hidden Build|Play state, keyboard-only workflows, or a layout that materially diverges from the reference.
